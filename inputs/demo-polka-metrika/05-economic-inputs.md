# Входы для сравнения направлений

Синтетическая записка финансовой команды. Горизонт — 12 месяцев с декабря 2026 года по ноябрь 2027 года. Валюта — рубли, без НДС. M1 — декабрь. Все будущие числа — гипотезы для сравнения, кроме утверждённых ограничений из 01-company.md.

## Базовый сценарий

Без инвестиций в новое направление для учебной модели сохраняем октябрьский операционный результат каждый месяц. Текущие продажи и штат финансируются базой. Обычный приток приблизительно компенсирует churn. При сравнении считайте только дополнительные поступления и расходы, включая потерянную денежную маржу каннибализированных подписок.

## Вариант A · Разовый отчёт перед закупкой

- Цена отчёта — 1 490 ₽, переменная себестоимость — 360 ₽. Ожидаемый CAC — 700 ₽ на нового покупателя отчёта. Для простоты одна покупка на клиента, CAC применяется один раз.
- Базовый прогноз покупок M1–M12: 0, 0, 100, 140, 180, 210, 230, 250, 270, 290, 310, 330.
- Запуск — 460 тыс. ₽ в M1 и 340 тыс. ₽ в M2. Поддержка направления — 45 тыс. ₽ ежемесячно с M3.
- Диапазон спроса — 65–130% базового прогноза при пределе в 3 200 уникальных контактов. Диапазон CAC — 450–1 050 ₽. Гипотеза каннибализации — ежемесячно 0–10 активных малых подписок с M4, базово 6. Учитывайте по каждой потерянной подписке разницу между ARPA и прямыми расходами. Покупки отчёта уже входят в прогноз.

## Вариант B · Предупреждения о потере маржи

- Доплата к действующей подписке — 4 900 ₽ в месяц. Переменная себестоимость дополнения — 1 100 ₽ на активную платящую доплату в месяц. Прогноз касается только доплаты. Базовая подписка остаётся в базовом сценарии.
- Активные доплаты M1–M12: 0, 0, 12, 24, 40, 55, 70, 85, 100, 115, 130, 145. Это количество оплаченных аккаунто-месяцев в каждом месяце, прогноз уже учитывает отток.
- Новые первые оплаты дополнения M1–M12: 0, 0, 12, 14, 18, 18, 18, 18, 18, 18, 19, 19. Применить стоимость продажи и онбординга 1 400 ₽ к каждой первой оплате один раз.
- Запуск — 420 тыс. ₽ в M1 и 380 тыс. ₽ в M2. Поддержка направления — 90 тыс. ₽ в месяц с M3.
- Диапазон спроса — 55–120% базового прогноза для доплат и первых оплат одновременно, с округлением. Верхняя граница зависит от числа подходящих аккаунтов внутри текущей базы. Переменные расходы — 850–1 650 ₽ на доплату в месяц. Отдельно проверьте сценарий, где подтверждена готовность платить только 3 500 ₽.
- Внутренний критерий качества для обсуждения — не менее 70% проверенных предупреждений приводят к подтверждённой проблеме по сверке с исходными строками. Порог предложения команды, эмпирически не подтверждён. Сигнал клиента — задокументированное решение по товару после предупреждения.

## Вариант C · Отчётность агентств с правами доступа

- Доплата — 10 900 ₽ на активное агентство в месяц. Дополнительные прямые расходы — 3 500 ₽ в месяц на активную доплату.
- Активные доплаты M1–M12: 0, 0, 0, 5, 9, 13, 17, 21, 25, 29, 33, 37. Новые первые оплаты: 0, 0, 0, 5, 5, 5, 5, 5, 5, 5, 5, 5. Первые оплаты за период включают клиентов, которые могли затем уйти.
- Дополнительный CAC и онбординг дополнения — 6 000 ₽ за первую оплату.
- Запуск — 440 тыс. ₽ в M1, 380 тыс. ₽ в M2, 360 тыс. ₽ в M3. Поддержка направления — 75 тыс. ₽ в месяц с M4.
- Диапазон спроса — 70–150% базового прогноза для доплат и первых оплат одновременно, с округлением. Дополнительные расходы на аккаунт — 2 500–5 000 ₽ в месяц. В верхней части диапазона спроса ожидаются сложности с переносом шаблонов. Их влияние на онбординг не измерено.

## Общие оговорки

Для учебной модели поступления и расходы отражаются в том же месяце. Числа округлять до тысяч ₽ в выводах, промежуточные расчёты можно вести до рубля. Дополнительное удержание базовых подписок в вариантах B и C не оценено. В базовом сценарии по каждому из этих двух вариантов не начисляйте выгоду от удержания. Для оценки рыночного потенциала можно отдельно рассмотреть продажу пакета новым клиентам, если явно учесть новый CAC, себестоимость и оплату подписки. Для первого пилота возможен ручной процесс, стоимость и длительность предстоит предложить.
