# product-strategy-agent

**Авторская методология Юлии Билинкис** · [Strategic Move Education](https://strategicmove.education/)

Агент для Codex на базе курса по продуктовой стратегии Strategic Move Education. Проект показывает, как участники курса применяют авторскую методологию к реальному продуктовому решению. За один запуск Codex анализирует материалы компании, рынка и клиентов, формулирует диагноз, выбирает сегмент, сравнивает стратегические ставки и их экономику. На выходе — Bet Card 2.0, план проверки и стратегия на одной странице.

## Как запустить

1. Скачайте или клонируйте репозиторий и откройте его папку в Codex.
2. Положите материалы в отдельную подпапку внутри `inputs/`, например `inputs/my-company/`. Подойдут интервью, аналитика, финансовые данные и заметки о рынке.
3. Отправьте в Codex запрос ниже, подставив имя своей папки.

> Используй [SKILL.md](SKILL.md) как инструкцию. Прочитай только материалы из `inputs/my-company`, пройди полный цикл по авторской методологии Юлии Билинкис и сохрани результаты в `strategy/my-company`.

Итог будет в `strategy/my-company/06-strategy-one-pager.md`. Рядом сохранятся источники, промежуточный анализ и расчёты. [Методология курса](references/course-method.md) · [Шаблоны результатов](references/strategy-artifacts.md)

## От стратегии к пилоту

Навык сохраняет черновик `intent.md` и запись `decision.md` с единым ID ставки. Владелец решения утверждает пилот, а после измерений фиксирует, продолжать ли работу и какое допущение пересмотреть. [Рабочий цикл и шаблоны](references/pilot-loop.md)

Для проверки учебного прогона из корня проекта:

```sh
node scripts/check-pilot.mjs strategy/demo-polka-metrika
node --test scripts/check-pilot.test.mjs
```
